# T2T Field Guide: backstage map

Pages stay at the top level (their web addresses never change). Everything else lives in a labeled folder.

| Folder | What lives here |
|---|---|
| `engine/` | The engine: session, Supabase connection, header data, helpers, desktop and TV frame |
| `briefing-board/` | The Briefing Board: master board, cards, card backs, live refresh, styles, canvas camera |
| `storyboard/` | Idea storyboard screens, idea capture, media, story-board template |
| `drawer/` | Drawer, backpack, gems, bookmarks |
| `people-team/` | Cast, member identity, invitations, team button, ID bands |
| `controls/` | Shared tools: (+) add, A-Z toggle, lasso, drag, shortcuts, settings, text and screen fit |
| `plans-and-tasks/` | Plan container, step markers, task marker, needs / plan / goals |
| `maps-and-library/` | Traveler map, developer map, topic pyramid, stories, library, notebook, document decomposition |
| `style/` | Site stylesheet |

Pages: `index.html` (home), `dream.html`, `believe.html`, `dare.html`, `journey.html`, `idea-details.html`.

Rule of thumb: one tree, one code. A shared behavior is built once, in one folder, and reused everywhere.

Shorthand used on the team: BB = Briefing Board, BS = Blue Sky, SEA = Sea of Ideas, SB = Story Board, PLN = Plan, CAST = the human stuff, LIB = Library, alpha = alphabetical.
